# 分數奇幻王國 - 四年級數學互動學習網 (math4-06)

專為國小四年級數學「分數」單元打造的互動闖關學習網站。

## 功能特色

1. **核心概念引導**：包含等值分數、真分數、假分數與帶分數互換視覺化教學。
2. **分數排序遊戲**：卡牌由小到大拖曳排序挑戰。
3. **分數教具操作板**：圓形披薩分塊與長條分數條切割著色互動。
4. **繪本情境關卡**：生活化蛋糕、披薩故事題，引導學生理解分數應用。
5. **分數數線互動**：在數線上標記分母與分數位置。
6. **王國冒險測驗**：即時回饋、計分結算與星星獎勵評量。
7. **懸浮草稿計算紙**：畫面上可隨時開展的草稿板，方便演算。
8. **大字級設計**：36px 標題與 24px 內文，支援平板與電子白板教學。
